
# Vector Editor CLI

Run:

docker compose up --build
docker compose run vector-cli

Commands:

 - create-point 1 2 (создать точку)
 - create-circle 0 0 5 (создать круг)
 - create-square 1 1 4 (создать квадрат)
 - create-segment 0 0 1 1 (создать отрезок)

list (просмотреть список фигур)
delete <id> (удалить фигуру)
exit (выйти)
